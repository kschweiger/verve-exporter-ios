# Product Specs

Product specs describe what the product or project should do.

Use this directory for:

- User-visible behavior.
- File format contracts.
- Business rules.
- Feature requirements.
- Acceptance criteria.
- Non-goals and constraints that affect product behavior.

Create a product spec before implementing new user-visible behavior when requirements are not already clear in repository-local docs.

## Current Specs

- `verve-geojson-format.md`: Current Verve GeoJSON export contract, including omitted moving duration, timestamp time zone, and empty-workout rules.
- `verve-swimming-metadata.md`: Shareable Verve swimming metadata contract for exporters, importers, and backend services.
